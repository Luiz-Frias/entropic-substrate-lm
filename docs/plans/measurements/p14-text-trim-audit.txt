Method
------
1. Roots searched: results/, data/, configs/, docs/, models/, .dvc/cache
   (the brief's five plus the authoring-time .dvc/cache leg named in
   Scope item 2 of the brief).
2. A file is CLAIMED DECODABLE, and json.loads is attempted on it, when
   EITHER its extension is .json/.jsonl OR `file`'s own magic classifies
   its content as "JSON data" regardless of extension. The second leg
   matters concretely here: 79 of the 88 `.dvc/cache` files are
   extensionless, content-addressed `files/md5/<hash>` blobs that `file`
   still content-sniffs as JSON, and they are already local (no DVC pull
   needed to read them) — an extension-only filter would have silently
   excluded them from the "claimed decodable" set, which is exactly the
   kind of quiet gap the fail-LOUD invariant forbids. A decode failure on
   a claimed-decodable file (or a malformed `*_base64` field, see below)
   is reported by path below under UNREADABLE; it is never dropped or
   counted as zero by omission.
3. Every successfully decoded JSON document is walked recursively — dicts,
   lists, and any string-valued key ending in `_base64`, which is
   base64-decoded, UTF-8-decoded and re-parsed as JSON, then walked in
   turn (decision contracts travel base64-encoded, per the brief, and can
   nest two layers deep: `input_manifest_base64` -> `decision_contract_base64`).
   A dict is a RECOGNIZED RECORD of schema S the instant it carries a
   `schema_version` or `schema` key (the campaign design uses `schema`,
   everything else uses `schema_version`) whose value is one of the five
   known schema strings enumerated from source:
     d1-launch-attempt-v1          (D1_LAUNCH_ATTEMPT_SCHEMA)
     d1-launch-ledger-v1           (D1_LAUNCH_LEDGER_SCHEMA)
     d1-decision-contract-v1       (_SCHEMA, d1_registration_codec.py)
     d-ladder-campaign-design-v1   (ladder_campaign.read_campaign_design)
     d-ladder-run-authorization-v1 (RunAuthorization.manifest)
   Recognition does not stop at the outer document: a nested dict with its
   own schema tag (a launch-attempt identity embedded inside a launch
   ledger's events, or a decision contract behind a base64 field) is a
   second, independently counted record.
4. For each recognized record, every string LEAF value anywhere in its own
   subtree is checked against the untrimmed predicate on decoded Python
   str, `v.strip() and v.strip() != v` (Python's own Unicode-whitespace
   rule for `.strip()`, never a regex over raw bytes), and tagged by its
   dotted field path relative to the record root. A nested sub-object that
   itself declares a different schema tag is excluded from the parent's
   leaf walk (counted as its own record instead, so nothing is double
   counted). This is deliberately a SUPERSET of the three focal codecs'
   own `_text`-gated fields: it can only over-count against
   `logical_run_id` / `verdict_vocabulary` / `cells[].*`, never
   under-count, and the per-path breakdown makes it possible to see
   exactly which named field, if any, actually carries drift.
5. A passing CONTROL CORPUS, built outside the repo in the session
   scratchpad, seeds one known-untrimmed record per schema — including one
   base64-nested decision contract, one two-layer base64 nesting, and one
   custody-embedded launch ledger matching `d1_finalized_cell_custody.py`'s
   embedding shape — plus one clean (trimmed) control record and two
   deliberately-broken files (invalid JSON, invalid base64) to prove the
   fail-LOUD path reports rather than swallows. Its full output is quoted
   verbatim below; every seed is recovered and every broken file is
   reported.

AUDIT SCRIPT
------------
```python
"""FOR-1614 persisted-record trim-semantics audit. Not committed."""
from __future__ import annotations

import base64
import json
import subprocess
import sys
from pathlib import Path

SCHEMAS = {
    "d1-launch-attempt-v1",
    "d1-launch-ledger-v1",
    "d1-decision-contract-v1",
    "d-ladder-campaign-design-v1",
    "d-ladder-run-authorization-v1",
}


class Unreadable(Exception):
    """A claimed-decodable file or base64 field could not be decoded."""


def untrimmed(value: str) -> bool:
    return bool(value.strip()) and value.strip() != value


def schema_of(node: object) -> str | None:
    if type(node) is not dict:
        return None
    for key in ("schema_version", "schema"):
        value = node.get(key)
        if type(value) is str and value in SCHEMAS:
            return value
    return None


def walk_leaves(node: object, path: str, into: dict[str, list[str]]) -> None:
    if type(node) is dict:
        for key, value in node.items():
            child_path = f"{path}.{key}" if path else str(key)
            if type(value) is dict and schema_of(value) is not None:
                continue
            walk_leaves(value, child_path, into)
    elif type(node) is list:
        for index, item in enumerate(node):
            walk_leaves(item, f"{path}[{index}]", into)
    elif type(node) is str:
        if untrimmed(node):
            into.setdefault(path, []).append(node)


def walk_records(node, path, source, records):
    schema = schema_of(node)
    if schema is not None:
        leaves: dict[str, list[str]] = {}
        walk_leaves(node, "", leaves)
        records.append((source, path, schema, leaves))
    if type(node) is dict:
        for key, value in node.items():
            child_path = f"{path}.{key}" if path else str(key)
            if type(value) is str and key.endswith("_base64"):
                try:
                    decoded_bytes = base64.b64decode(value, validate=True)
                except Exception as error:
                    raise Unreadable(f"{source}:{child_path}: invalid base64: {error}") from error
                try:
                    decoded_json = json.loads(decoded_bytes.decode("utf-8"))
                except (UnicodeDecodeError, json.JSONDecodeError):
                    continue
                walk_records(decoded_json, f"{child_path}(base64)", source, records)
            else:
                walk_records(value, child_path, source, records)
    elif type(node) is list:
        for index, item in enumerate(node):
            walk_records(item, f"{path}[{index}]", source, records)


def _magic_json_paths(root: Path) -> set[Path]:
    all_files = [p for p in root.rglob("*") if p.is_file()]
    if not all_files:
        return set()
    proc = subprocess.run(["file", "-f", "-"], input="\n".join(str(p) for p in all_files),
                           capture_output=True, text=True)
    hits: set[Path] = set()
    for line in proc.stdout.splitlines():
        path_str, _, desc = line.rpartition(": ")
        if "JSON data" in desc:
            hits.add(Path(path_str))
    return hits


def scan_root(root: Path):
    records, unreadable = [], []
    if not root.exists():
        return records, unreadable, 0
    magic_json = _magic_json_paths(root)
    candidates = sorted({p for p in root.rglob("*") if p.is_file()
                          and p.suffix in (".json", ".jsonl")} | magic_json)
    for path in candidates:
        source = str(path)
        try:
            text = path.read_text(encoding="utf-8")
        except UnicodeDecodeError as error:
            unreadable.append(f"{source}: not UTF-8: {error}")
            continue
        if not text.strip():
            continue
        whole_doc_error = None
        try:
            document = json.loads(text)
        except json.JSONDecodeError as error:
            whole_doc_error, document = error, None
        if document is not None and path.suffix != ".jsonl":
            try:
                walk_records(document, "", source, records)
            except Unreadable as error:
                unreadable.append(str(error))
            continue
        line_failures, any_line_ok = [], False
        for line_no, line in enumerate(text.splitlines(), start=1):
            if not line.strip():
                continue
            try:
                line_doc = json.loads(line)
            except json.JSONDecodeError as error:
                line_failures.append(f"{source}:{line_no}: invalid JSON: {error}")
                continue
            any_line_ok = True
            try:
                walk_records(line_doc, "", f"{source}:{line_no}", records)
            except Unreadable as error:
                unreadable.append(str(error))
        if any_line_ok:
            unreadable.extend(line_failures)
        elif whole_doc_error is not None:
            unreadable.append(f"{source}: invalid JSON (whole-doc and per-line): {whole_doc_error}")
    return records, unreadable, len(candidates)


def report(label: str, roots: list[Path]) -> None:
    print(f"\n=== {label} ===")
    total_records = total_untrimmed = json_file_count = 0
    per_schema: dict[str, dict[str, int]] = {}
    all_unreadable: list[str] = []
    for root in roots:
        records, unreadable, scanned = scan_root(root)
        json_file_count += scanned
        all_unreadable.extend(unreadable)
        for source, path, schema, leaves in records:
            total_records += 1
            bucket = per_schema.setdefault(schema, {"records": 0, "untrimmed_fields": 0, "untrimmed_records": 0})
            bucket["records"] += 1
            if leaves:
                bucket["untrimmed_records"] += 1
                n = sum(len(v) for v in leaves.values())
                bucket["untrimmed_fields"] += n
                total_untrimmed += n
                for field_path, values in leaves.items():
                    print(f"  UNTRIMMED {schema} @ {source}#{path or '<root>'} field={field_path!r} "
                          f"count={len(values)} example={values[0]!r}")
    print(f"  JSON/JSONL files scanned: {json_file_count}")
    print(f"  Recognized records: {total_records}")
    for schema in sorted(SCHEMAS):
        b = per_schema.get(schema, {"records": 0, "untrimmed_fields": 0, "untrimmed_records": 0})
        print(f"  schema={schema}: records={b['records']} "
              f"untrimmed_records={b['untrimmed_records']} untrimmed_fields={b['untrimmed_fields']}")
    print(f"  Total untrimmed-but-nonblank string leaves across all recognized records: {total_untrimmed}")
    if all_unreadable:
        print(f"  UNREADABLE ({len(all_unreadable)}):")
        for entry in all_unreadable:
            print(f"    {entry}")
    else:
        print("  UNREADABLE: none")


def main() -> None:
    report("LIVE CORPUS (main checkout)",
           [Path(p) for p in ("results", "data", "configs", "docs", "models", ".dvc/cache")])
    if len(sys.argv) > 1 and sys.argv[1] == "--control":
        report("CONTROL CORPUS (scratchpad, seeded)", [Path(sys.argv[2])])


if __name__ == "__main__":
    main()
```
