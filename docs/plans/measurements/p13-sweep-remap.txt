Why a mapping is derived from the tree rather than reusing tools/mapping.json
------------------------------------------------------------------------------
tools/mapping.json stays FROZEN and byte-identical (P13-MAPPING restated); it is not retired
and not edited. remap_check.py exits 1 on any module referenced by edges.json but absent from
the mapping's `modules` map, and it is keyed by tools/import_graph.py's own modname()
convention over the post-B2 landed tree. tools/mapping.json predates the p8/p9 sub-package
refinement and does not carry every landed module name in that exact form, so a mapping
DERIVED from the current tree is the only one that can cover every node the current graph
discovers. This is the baseline P13-BASELINE calls for; it is a distinct artifact from
tools/mapping.json, produced beside it, never in place of it.

Exact reproducing procedure (no absolute path, no username, cwd = repo root; reproduces the
committed mapping file byte for byte -- verified by regenerating and `cmp`-ing before this
commit):

    uv run python - <<'PYEOF' docs/plans/measurements/p13-sweep-mapping.json
    import json
    import sys
    from pathlib import Path

    sys.path.insert(0, "tools")
    import import_graph as ig

    root = Path("src/entropic_substrate")
    pkg = "entropic_substrate"

    files = sorted(p for p in root.rglob("*.py") if "__pycache__" not in p.parts)
    mods = {}
    for p in files:
        mods[ig.modname(p, root, pkg)] = p

    layers = ["kernel", "core", "ladder", "historical", "composition"]
    layer_set = set(layers)
    roots = {"entropic_substrate", "entropic_substrate.__main__"}

    def layer_of(mod):
        if mod in roots:
            return "composition"
        seg = mod.split(".")[1]
        if seg not in layer_set:
            raise SystemExit(f"FATAL: {mod} first segment {seg!r} outside the five landed layers")
        return seg

    def dest_of(mod):
        if mod in roots:
            return "entropic_substrate.composition"
        parts = mod.split(".")
        return mod if len(parts) <= 3 else ".".join(parts[:3])

    modules_out = {m: {"dest": dest_of(m), "layer": layer_of(m)} for m in sorted(mods)}

    out = {
        "layers": layers,
        "layer_rule": "the first dotted path segment under entropic_substrate (kernel/core/ladder/historical/composition); both root modules (entropic_substrate, entropic_substrate.__main__) have no such segment and are pinned to layer composition, matching tools/mapping.json's own root rows",
        "dest_rule": "truncate the dotted module path to its first 3 segments (entropic_substrate.<layer>.<subpackage>); a module with 3 or fewer segments maps to itself; both root modules are pinned to entropic_substrate.composition, matching tools/mapping.json's own root rows",
        "modules": modules_out,
        "_provenance": {
            "derived_from": "the src/entropic_substrate tree, module set and modname() convention from tools/import_graph.py",
            "epoch": "f7b8a21adb74c68813113d0b6f3b9433e7ec70a4",
            "purpose": "feeds tools/remap_check.py for the p13-sweep post-B2 baseline (P13-BASELINE); distinct from tools/mapping.json, which stays frozen and byte-identical (P13-MAPPING)",
        },
    }

    Path(sys.argv[1]).write_text(json.dumps(out, indent=2) + "\n")
    print(len(modules_out), "modules")
    PYEOF

measured all four candidate depths against this same edges.json before choosing the committed
rule, to make the granularity choice and its consequence explicit:

  depth 3 (dest = entropic_substrate.<layer>.<subpkg>):    4 package-level cycles  <- COMMITTED
