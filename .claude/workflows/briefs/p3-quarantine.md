## Scope

git mv the whole package into __legacy/ with zero byte edits, then generate one alias shim per old dotted LEAF path from tools/mapping.json. Package `__init__.py` files are never shimmed (RETRACTED 2026-09-18): the 12 originals are restored unmodified. Each shim static-imports its target so grimp sees the chain. RULED 2026-09-20 (operator, option (b) of the design-gate DECISION of wf_7f27b290-e61): each leaf shim is a PAIR, the 3-line `.py` alias plus a `.pyi` stub, because basedpyright (which `just check` runs in strict mode at a 0-error baseline) cannot see through the `sys.modules` rebind and would report every surviving old-prefix `from entropic_substrate.X import Name` (MEASURED: 1741 lines in 296 files inside the quarantine plus 80 names in the 7 restored facades). The stub is type-level only: CPython never imports a `.pyi`, so the sentinel-singleton identity, the rebind and the grimp-visible static import are untouched; `tools/import_graph.py` globs `*.py`, so stubs add no graph edges (PROBED 2026-09-20 with the repo's basedpyright: 9 errors without the stub, 0 with it; the rebound module object stays identical at runtime). `tools/gen_shims.py` emits both files per non-retired, non-pending row, records the stub path in the emitted-files manifest, and `--verify` recomputes the stub derivation and compares. STUB TEXT (conductor refinement 2026-09-20 inside option (b), resolving the three items of wf_7f55472a-499's design gate, each MEASURED with a control): NOT `from <target> import *`. A star stub honours the target's `__all__` (12 target modules omit names their importers use: 26 distinct (target, name) pairs, 45 import sites would go `reportAttributeAccessIssue`; 3 sites import underscore names a star can never re-export) and raises ruff F403, which `just lint` cannot auto-fix. The stub is instead DERIVED from the target module's own AST: one `from <target dotted> import <name> as <name>` line per module-level binding (assignments, defs, classes, import-bound names, names bound in top-level `if`/`try` blocks including `if TYPE_CHECKING:`, underscore names included), sorted, plus `__all__` when the target defines one. The generator's derivation function is the single source; `--verify` re-derives from the target on disk and fails loud on any difference. Zero byte edits still holds: no `__all__` list is touched, no `[tool.basedpyright]`, ruff per-file-ignore or pre-commit change. No `[tool.basedpyright]` change (the p0 packaging door `include == ["src", "scripts"]` stands), no `.pre-commit-config.yaml` change, no typecheck carve-out; p13 deletes the stubs with the shims. RETRACTION (house rule 4, conductor, 2026-09-20, third design gate wf_43ef5138-4bc): this Scope previously said "the seven restored facades resolve through the sibling shim pairs like any other consumer, so zero byte edits stands". True for the RESTORED copy at the old path; MEASURED FALSE for the MOVED copy under `__legacy/<pkg>/__init__.py`: Python executes a package's `__init__.py` before any child, so importing any quarantined child runs the moved facade body, whose absolute old-prefix self-child re-export re-enters the sibling leaf shim while that shim is still mid-execution (no attributes until its final rebind line) -> `ImportError: cannot import name ... from partially initialized module` (probe with control, all 7 facade packages: data, geometry, init, layers, models, observation, predictive_state). The failure is LOAD-ORDER DEPENDENT: importing `__legacy.<pkg>` first warms the chain, and p0's exhaustive sweep sorts `_` before every letter, so it can stay GREEN while every real consumer path raises. RULING (conductor, option (a) of that gate; settled, do NOT re-raise): the MOVED copy of exactly those seven facade `__init__.py` files is EMPTIED to a docstring-only file (present on disk so setuptools `find_packages` discovery and p0's packaging pin hold; the docstring names this retraction and the original's byte count), in the same commit as the `git mv`; the RESTORED copies at the old paths stay verbatim; the other moved files keep zero byte edits (Non-goals carve-out below). Rationale is the plan's own mechanism item 3 (destination packages ship an empty `__init__.py`; zero measured inbound edges at the `__legacy.<pkg>` dotted name). Identity impact nil, measured by the gate: no facade `__init__.py` is inside either frozen H identity or the checkpoint reader's explicit leaf list. `tools/gen_shims.py`'s docstring paragraph claiming "TWO copies of that file execute" carries the same wrong premise and is corrected by the lane (constraint C9). SECOND (same gate): the emitted shim text must be a ruff fixed point; reordering `import sys` ahead of the target import inside `shim_source()` is INSIDE the ruled shim form (the ruling pins the static import THEN the rebind, not where `import sys` sits) and is an in-envelope edit to `tools/gen_shims.py`.
